PANDA BROWSER - WINDOWS EXE BUILD FILES

This project builds a Windows x64 PandaBrowser.exe with a dark green Panda start page.

To build:
1. Install the free .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. Ensure Microsoft Edge WebView2 Runtime is installed (often already present on Windows).
3. Double-click Build-PandaBrowser.bat.
4. When it finishes, the executable is in the publish folder: PandaBrowser.exe

This environment cannot compile/test a Windows EXE directly, so these are the complete build files, not a precompiled EXE.
